# Mr.Holmes Roadmap

## Vision
Transform Mr.Holmes from a collection of OSINT utilities into a more professional, modular investigation platform with a modern interface and clearer workflows.

## Short-term goals
- Improve the onboarding experience with a cleaner README and usage flow
- Introduce a dashboard-style main screen for recent investigations and summaries
- Improve reporting with timeline, confidence scoring, and executive summaries
- Modularize the core components so new modules can be added more safely

## Medium-term goals
- Add a REST API for domain, email, username, and phone searches
- Introduce a plugin architecture for additional OSINT modules
- Improve the GUI with a more modern layout and navigation
- Generate richer HTML and PDF reports

## Long-term goals
- Support richer visual analytics and maps
- Add structured case management for multiple investigations
- Improve testing and CI for stability
- Expand documentation for contributors and users
